### 独立レビューで修正した境界条件

- 同じUUIDに別の名前/結果が混入した場合、旧正常レコードを上書きせず競合失敗として隔離する。保存済み`sent`の読み戻しでも全文ペイロード一致がなければ新結果を送信済みへ昇格しない。
